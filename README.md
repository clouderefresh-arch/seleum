# ОЛС

Сайт, презентация и фирменный бланк ООО «ОЛС» (Юнайтед Лоджистикс Системс).

Прайс на сайте не публикуется. Заявка уходит письмом на info@olslogistic.ru через почтовую программу посетителя. Телефон диспетчера: +7 903 579-58-51.

## Страницы

- `index.html` — сайт: кто мы, как проходит рейс, база в Коледино, форма заявки
- `presentation.html` — презентация для заказчика, листается стрелками, печатается в PDF
- `blank.html` — фирменный бланк A4

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Готовые файлы появятся в `dist/`.
